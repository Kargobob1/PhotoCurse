PhotoCurse portable mode

While this file sits next to photocraft.exe, PhotoCurse keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the PhotoCurseData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move PhotoCurse with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Photocraft) instead.
If PhotoCurseData can't be written (for example on a read-only drive), PhotoCurse says so and
uses %APPDATA%\Photocraft instead.
